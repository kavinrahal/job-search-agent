# Job Search Criteria

## Location
Full-time roles in Australia. Melbourne preferred; Sydney is acceptable. Remote roles are acceptable if the employer is Australian-based.

## Experience Level
Mid-level positions only. Exclude junior roles and senior / lead / principal / staff / architect roles.

## Salary
Target: $120,000 AUD base salary per year. Negotiable around this figure.

## Visa Sponsorship
Visa sponsorship is required.
- **Exclude** roles that explicitly state they do not sponsor visas.
- **Include** roles that mention sponsorship is available.
- **Include** roles that do not mention sponsorship either way — these remain candidates until confirmed otherwise.

## Technical Stack
Strong preference for roles using any of:
- React, TypeScript, JavaScript
- ASP.NET Core, C#, .NET
- Azure (App Services, Functions, SQL, Data Explorer, Digital Twins)

Adjacent stacks that are acceptable:
- Node.js, Angular, GraphQL
- AWS or GCP where Azure experience transfers

## Industry
Open to all industries. Bonus relevance for:
- Property technology
- IoT and digital twin platforms
- Payments and fintech
- AI tooling and developer tooling
